# Sky Climber

Sky Climber is an original Canvas 2D browser game scaffold for a vertical tower-jumper: run left and right, jump from platform to platform, climb above the camera, and keep a score/combo loop ready for fuller gameplay polish.

## Controls

- Move: Arrow Left / Arrow Right or A / D
- Jump / start / restart: Space, W, or Arrow Up
- Pause / resume: P or Escape
- Mobile: tap to start, then use the on-screen left, right, jump, and pause buttons

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Build and test

```bash
npm run build
npm test
```

## Deployment

`npm run build` writes a static app to `dist/`. The Vite base path is `./`, so the contents of `dist/` can be hosted from any static web server or subdirectory.

## Originality note

Sky Climber uses original placeholder geometry, colors, UI text, and naming. It does not include copied assets, names, characters, music, sounds, logos, or level art from any existing vertical tower-jumper game.
